# Copy Checkpoint on macOS ARM64

The source-isolated native package matches the pinned original and independent oracle across 290 native constructions and 1,827 binary decodes. The witness compares complete fields, exact binary bytes and named errors. It exercises all phases, signed arithmetic overflow and underflow, footer precedence, and path, identity and offset boundaries. A repinned domain mutation emits the independently predicted different footer and rejects the original footer.
