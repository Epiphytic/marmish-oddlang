# Copy field relations on macOS ARM64

The source-isolated package matched the pinned original and an independent oracle across 14 Manifest matches, 56 start validation calls and 24 build validation calls. The checks cover single-field differences, a valid match with invalid record data, codec-dependent digest selection and ordered errors. An exact mutation moved the digest call ahead of identity checks and changed the expected mismatch into a propagated path failure.
