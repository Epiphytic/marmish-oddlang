# Native status client v1

The status workspace adds one live command to the [native CLI parser](../native-cli-v1/). The manually recovered and independently checked graph routes `marmish --state-dir DIR --socket SOCKET status` to a same-user Unix socket. It sends big-endian length 22 followed by the compact JSON object `{"operation":"status"}`, then closes the write half. It reads one positive JSON frame of at most 65,536 bytes. The request and response share one 180-second deadline. The protocol version belongs to the graph release. The original framing contains no version field.

A valid reply is rendered as an ordered compact JSON line, with exit 0 or 1 from `ok`. Local I/O, peer identity, size, JSON and deadline failures have finite process diagnostics. The profile accepts omitted or null `command` and `stream` reply fields for status. The original also accepts positional replies such as `[true,null,null]` and non-null extensions such as `{"command":{"state":"local_busy"}}` and `{"stream":{"state":"pending"}}` with `"ok":true`. The generated v1 client reports `ipc_frame_json` for those examples. Their schema, including handling of additional fields inside typed variants, remains unqualified. Argument checks preserve foreground, server-limit, new-session, then route-mode precedence.

The qualified lane uses a development-layout binary, an explicit state directory and an explicit socket path, a pinned original macOS ARM64 daemon and same-user peers. The real daemon reports its activation snapshot without a relay handshake. The independent harness also compares 17 controlled peer cases and five argument guard outcomes. The 68 parser observations still match. Automatic socket discovery and profile manifest validation, installed executable validation, daemon-side generation, startup reporter flags, process-limit initialization and every other live command remain open. The generic fixture verifies deadline behavior with a shorter bound. A 180-second stalled peer is unqualified for this profile. Missing explicit path arguments exit 125 with a scope diagnostic.

The [workspace manifest](../native-status-workspace.json) pins the shared CLI graph, status component and exact original-release registry closure. See the [status client qualification](../../../verification/whole/status/client-README.md) for the source-isolated reproduction and receipt.
