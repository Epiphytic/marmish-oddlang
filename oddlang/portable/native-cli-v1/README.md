# Native CLI parser candidate

`graph.json` is a candidate recovered from the public Clap parser in the pinned Marmish 0.3.1 release. The ordered tree preserves visible and hidden commands, option spelling and help metadata, typed positional values and options, repeatability, defaults, numeric bounds, selector groups and command-specific requirements and conflicts. The reviewed Rust bindings set each executable name and parse-error policy and assign stable IRIs to recognized commands. Clap 4.6.7 supplies the Rust parser and help renderer.

The 68 recorded process observations cover help, version and unknown-option handling for both executables. They compare exact bytes on stdout and stderr, plus exit status, with an independent original-release fixture. `help status` exercises the grammar for `status`. Daemon status, client and daemon dispatch, private helper protocols and rsync handling remain open. A recognized command has a stable IRI available for a native adapter. The generated parser-only binaries return 125 for recognized operations without a handler.

With the Oddlang compiler built from `c01279eb61ed9e86b51b2eeaf0c5b744397c74a3`, reproduce recovery against the pinned revision with `python3 verification/whole/cli/project.py recover ODDLANG ORIGINAL`. The driver checks the parser, package manifest and dependency lock from the selected revision. It compares the regenerated graph with this file and verifies that the generated Rust dependency pins match registry entries in the original release lock. The source-free build takes `workspace.json`, whose member package pins the graph, both bindings and the Rust dependency lock. It generates two native binary entrypoints and verifies the package and workspace locks.
