# Foreground native daemon qualification

Run on macOS ARM64 with Rust 1.97.1, a clean pinned Oddlang checkout, original source and the pinned native original release binary directory.

```sh
verification/whole/foreground-owner/macos.sh FRAMEWORK ORIGINAL ORIGINAL_BINS OUTPUT RECEIPT
```

The runner checks source and package selections, including the shared endpoint discovery layout. It builds the compiler and generates the native daemon package from graph and lock in a staged file allowlist with no network or access to original inputs or oracle. It compares package and Cargo locks and builds the actual release executables offline. The qualification then runs separately with a temporary private profile generated by the original `marmish init`. No fixture credential is published.

Both original and generated foreground daemons make a real TLS ClientHello. The pinned original client discovers the live runtime and produces the same activating status against either daemon. Each implementation excludes the other using the real profile lock. Signal shutdown releases local resources and supports reattachment. The same generated daemon recovers its verified stale runtime after an intentional SIGKILL. The owners reject plaintext. The controlled TLS peer uses a deliberately untrusted local certificate to elicit the same finite relay-connect failure. Original provider shutdown output is recorded separately. The generated daemon only owns local cleanup.

Qualified controls cover credential mismatch and mode, runtime collision, the parser transcript, and the actual ordinary binary and CLI flags in this lane. The [foreground contract](../../../oddlang/portable/native-foreground-owner-v1/) lists the remaining obligations. Candidate hashes identify tested instances. The contract evidence compares graph and lock bytes and process observations.

The [macOS ARM64 receipt](generated-macos-arm64.json) records the exact clean generation inputs and original/native mixed results.
